# Student Grades Manager

## About the Project
Student Grades Manager is a console-based C++ application that helps manage student grades and analyze academic performance.

## Features
- Enter the number of students and their names.
- Enter grades for six subjects.
- Validate student count and grade values.
- Display all students with their total grades and averages.
- Calculate the class average.
- Search for a student by name and display their grades.
- Sort students by total grade in descending order.
- Search for grades by subject.
- Display the top 10 students.

## Subjects
The program manages grades in six subjects:
- IS
- SA
- LA
- LD
- DS
- CPS

Each grade must be between 0 and 100.

## Technologies Used
- C++
- Standard Template Library (STL)

## How to Run
1. Clone or download this repository.
2. Open the C++ source file in a C++ IDE, such as CLion.
3. Compile and run the program.
4. Follow the instructions displayed in the console.
